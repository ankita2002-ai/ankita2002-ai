## About Me

I'm a final-year Computer Science undergraduate at **Maharana Pratap Group of Institutions, Kanpur (AKTU, Lucknow)**, expected to graduate in **2027**. I enjoy turning coursework into working software — from a hospital records system built to manage real patient and appointment data, to a national-level hackathon project built under time pressure as part of **Smart India Hackathon (SIH) 2024**.

I'm comfortable with **Java, Python, and SQL**, and have spent recent months exploring **generative AI** through hands-on workshops and mentorship programs, including a Gen-AI camp mentored by a Microsoft engineer and an AI tools workshop covering Claude-assisted presentations, data analysis, and code debugging.

I'm still early in my engineering journey — I don't have professional work experience yet — but I pick up new tools quickly and care about writing organized, understandable code.

**Open To:**
- Entry-level Software Development roles
- IT Support roles
- QA Testing roles
- Internship and mentorship opportunities in AI/ML
